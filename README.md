# harfbyhia.in

Coming-soon page for Harf by HIA. Plain static files: Vercel serves them as they are, no build step.

- `index.html` – the page (fonts from Google Fonts, everything else inline)
- `favicon.svg` – browser tab icon

Deploy: push to GitHub → Vercel auto-deploys the `main` branch.

Later, the full Next.js shop (see `docs/HANDOFF.md`) replaces these files in this same repo.
